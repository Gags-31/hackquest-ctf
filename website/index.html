root@hackquest:~$ Event Overview

HackQuest CTF is a hands-on cybersecurity competition built as a five-round progressive gauntlet. Every challenge you crack hands you a code segment — collect a round's worth and they assemble into the key that unseals the next one. Nothing unlocks until you earn it.

Round 1 opens with logic puzzles in base-36. Round 2 cracks Caesar, Base64 and ROT13. Round 3 tests you with tech riddles. Round 4 is a web-security capture-the-flag. The finale is a live coding debugging sprint — fix the broken function, pass the tests, and the winning flag is yours. Teams of 2–4. 3h 45m on the clock. Highest score takes the crown.

// The Five Rounds

A progressive gauntlet. Every challenge you solve reveals a code segment — collect them all and they concatenate into the code that unlocks the next round.

▓ How progression works
  1. Join your team to unlock Round 1.
  2. Each challenge you solve hands you a 3–4 character code segment.
  3. Complete every challenge in a round to collect all its segments.
  4. The segments join in order to form the unlock code for the next round.
  5. Rounds stay locked until the previous round is cleared — the next challenge only appears once the current one is solved.
  6. Answers are never displayed. Ever.
