## 1. Overview
HackQuest CTF is a hands-on cybersecurity competition introducing participants to practical web security concepts via intentionally vulnerable, controlled challenges. Each challenge hides a flag participants must discover and submit (example: `CTF{hackquest_web_warrior}`). Teams score per flag; the highest scorer wins. Challenges progress from basic to advanced.

## 2. Objectives
- Introduce students to practical cybersecurity
- Hands-on exposure to web vulnerabilities
- Develop logical and analytical problem-solving skills
- Encourage ethical hacking practices
- Promote teamwork and technical collaboration
- Show how vulnerabilities occur in real-world web applications
- Encourage students to explore cybersecurity as a career
- Strengthen Pragyan Club × IEEE collaboration

## 3. Event Format
Each challenge provides: description, difficulty level, point value, target environment/file, optional hints, and a flag submission field. Correct submission: `✓ Correct Flag! +200 points`. Incorrect: `✕ Incorrect Flag. Try again.` A live scoreboard tracks rankings.

## 6. Difficulty
- 🟢 **Easy** — HTML, browser dev tools, HTTP, encoding, cookies, basic authentication
- 🟢 **Medium** — SQL injection, XSS, IDOR, sessions, authentication, information disclosure
- 🟢 **Advanced** — File upload vulnerabilities, authentication bypass, application logic flaws
- 🔴 **Hard** — Blind SQL injection, SSRF, JWT security

## 7. Hint System
Hints cost a 25-point penalty each. Example — Challenge "SQL Injection" (200 pts):
- Hint 1 (-25): "Look closely at how the application handles user input."
- Hint 2 (-25): "Think about how database queries are constructed."

## 8. Scoreboard & Tie-Breaker
Live scoreboard ranks teams by solves and score. Ties are broken by who achieved the score earlier.

## 9. Team Structure
Member 1: Web security · Member 2: Programming · Member 3: Forensics/OSINT · Member 4: General problem solving.

## 10. Rules & Ethical Guidelines
1. Only systems explicitly provided for HackQuest CTF may be targeted.
2. Attacking the CTF platform itself is prohibited.
3. Attacking other participants/teams is prohibited.
4. DoS/DDoS attacks strictly prohibited.
5. No targeting college systems/networks.
6. No attacking external websites.
7. No sharing flags between teams.
8. No interfering with another team's challenge environment.
9. Report any infrastructure vulnerability to organizers.
10. Violations may lead to disqualification.
11. Organizing committee has final authority.
