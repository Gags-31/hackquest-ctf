# HackQuest CTF — Organizer Checklist

## Two Weeks Before
- [ ] Finalize event collaboration (Pragyan × IEEE × Codenex)
- [ ] Confirm venue & date
- [ ] Finalize rules & scoring
- [ ] Open registrations
- [ ] Begin challenge development & publicity

## One Week Before
- [ ] All 15 challenges finalized
- [ ] Challenge environments deployed (isolated)
- [ ] All flags tested & documented
- [ ] Volunteers assigned (coordinators 2, tech 3, registration 2, support 2, infra 1, media 1–2)
- [ ] Participant instructions prepared
- [ ] Infrastructure test: network, power backup, scoreboard

## Three Days Before
- [ ] Full mock CTF run
- [ ] Every challenge tested from a participant's view
- [ ] Scoring verified end-to-end
- [ ] Server capacity & internet check
- [ ] Promotional material finalized

## One Day Before
- [ ] Final deployment of all challenges
- [ ] Verify all challenges, flags, scoreboard
- [ ] Print registration materials & badges
- [ ] Brief volunteers

## Event Day
- [ ] 10:00 — Registration & team verification
- [ ] 10:20 — Welcome
- [ ] 10:35 — Rules & platform demo
- [ ] 10:50 — Practice challenge
- [ ] 11:00 — Competition starts; monitor servers/scoreboard/issues
- [ ] 2:45 — Submissions close, scoreboard freeze
- [ ] 2:55 — Score verification
- [ ] 3:05 — Winners & prize distribution
- [ ] 3:20 — Closing & group photo

## Post-Event
- [ ] Publish final results
- [ ] Distribute certificates
- [ ] Collect feedback
- [ ] Event photos & report
- [ ] Document technical issues & lessons learned
- [ ] Review challenge difficulty; share highlights officially
