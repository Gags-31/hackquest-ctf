▓ How the arena works
  1. Join your team to unlock Round 1.
  2. Each challenge you solve reveals a 3–4 character code segment.
  3. Finish every challenge in a round to collect all its segments.
  4. The segments concatenate (in order) into the unlock code for the next round.
  5. Rounds stay locked until the previous round is complete. Answers are never shown — you always get the next challenge only after solving the current one.
  6. Clear all five rounds to trigger the Live Coding Debugging Finale, which reveals your winning position.

🧩 Round 1 — Logic Labyrinth · 100 pts each

Three puzzles: summation, Fibonacci, and exponentiation. Convert each numeric answer to base-36.

🔐 Round 2 — Cipher Vault · 200 pts each

Three ciphers: Caesar (+3), Base64, and a reversed ROT13.

🧠 Round 3 — Tech Riddles · 300 pts each

Four riddles spanning mathematics, computing fundamentals, networking, and data structures.

🚩 Round 4 — Capture The Flag · 400 pts each

Four web-security questions: directory discovery, SQL injection, hashing, and rotation ciphers.

🛠 Final Round — Live Coding Debugging · 500 pts

Debug a broken function until it passes every test case. Solving it outputs the winning flag and your final position.
